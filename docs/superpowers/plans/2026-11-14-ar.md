# AR "See it in your room" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 3D tab on 11 device profiles that shows the NASA model, opens it in AR on phones, and shows a QR code (to `/?ar=<id>`) on laptops.

**Architecture:** One component (`DeviceModel`) wraps `<model-viewer>`, lazy-loaded so the main bundle doesn't grow. `Profile` gets a third tab; `App` reads `?ar=` once and, for a valid device with a model, renders a small `ArView` instead of the game. Models and the Draco decoder are static files under `public/`, so nothing is fetched from other sites at runtime.

**Tech Stack:** Vite 8, React 19, TypeScript 7, Tailwind v4, `@google/model-viewer@4.4.0`, `uqr@0.1.3`. Both packages are already installed (spike).

**Spec:** `docs/superpowers/specs/2026-11-14-ar-design.md`

## Global Constraints

- No network calls at runtime except our own static assets (CLAUDE.md). The Draco decoder is served from `/draco/`.
- Never hard-code UI strings in components: they go in `src/content/i18n/en.ts`.
- Kids 8–12: buttons ≥ 44 px, contrast ≥ 4.5:1, real `<button>` elements, aria-labels on icon buttons; use the house `Button` (`src/components/Button.tsx`) and semantic color tokens (`bg-cta`, `text-text`, `text-text-muted`, `text-fact`…).
- Respect `prefers-reduced-motion`: no `auto-rotate` when it is set.
- Each GLB < 3 MB.
- Before finishing: `npm run build` and `npm run lint` pass.
- Commits: only when the user has asked for them. Commit steps below are for that case.
- There is no unit-test runner in this project (Node 20, no Vitest). Checks are `npm run build` (type check) plus browser checks in the Browser pane against the `astrotales` dev server (`.claude/launch.json`, port 5199) or the `dev` server from the parent folder.

- [ ] **Step 2: Write `src/components/DeviceModel.tsx`**

```tsx
import { useEffect, useRef, useState } from 'react'
import type { ModelViewerElement } from '@google/model-viewer'
import { renderSVG } from 'uqr'
import Button from './Button'
import type { Device } from '../content/types'
import { en } from '../content/i18n/en'
import { useMedia } from '../hooks/useMedia'

const t = en.ar
const NASA_3D = 'https://science.nasa.gov/3d-resources/'

// model-viewer (and its WebGL code) is big: load it only when a 3D view opens.
// The Draco decoder location must be set before the library loads, or it fetches from Google's CDN.
let loadLib: Promise<unknown> | undefined
function loadModelViewer() {
  const w = window as unknown as { ModelViewerElement?: object }
  w.ModelViewerElement = { ...w.ModelViewerElement, dracoDecoderLocation: '/draco/' }
  return (loadLib ??= import('@google/model-viewer'))
}

export default function DeviceModel({ device, className = '' }: { device: Device; className?: string }) {
  const ref = useRef<ModelViewerElement>(null)
  const [ready, setReady] = useState(false)
  const [state, setState] = useState<'loading' | 'ar' | 'no-ar' | 'error'>('loading')
  const still = useMedia('(prefers-reduced-motion: reduce)')

  useEffect(() => {
    loadModelViewer().then(() => setReady(true), () => setState('error'))
  }, [])

  useEffect(() => {
    const mv = ref.current
    if (!mv) return
    const onLoad = () => setState(mv.canActivateAR ? 'ar' : 'no-ar')
    const onError = () => setState('error')
    mv.addEventListener('load', onLoad)
    mv.addEventListener('error', onError)
    return () => {
      mv.removeEventListener('load', onLoad)
      mv.removeEventListener('error', onError)
    }
  }, [ready])

  if (!device.model3d) return null
  // The QR opens this same machine on a phone (App reads ?ar=).
  const link = `${location.origin}${location.pathname}?ar=${device.id}`

  return (
    <div className={`relative ${className}`}>
      {ready && state !== 'error' && (
        <model-viewer
          ref={ref}
          src={device.model3d}
          alt={device.name}
          ar=""
          ar-modes="webxr scene-viewer quick-look"
          ar-scale="auto"
          camera-controls=""
          auto-rotate={still ? undefined : ''}
          shadow-intensity="1"
          style={{ width: '100%', height: '100%' }}
        >
          <Button slot="ar-button" className="absolute bottom-4 left-1/2 -translate-x-1/2">{t.button}</Button>
        </model-viewer>
      )}

      {state === 'loading' && <p className="pointer-events-none absolute inset-0 grid place-items-center text-text-muted">{t.loading}</p>}
      {state === 'error' && <p className="grid h-full place-items-center p-4 text-center text-text-muted">{t.error}</p>}

      {state === 'no-ar' && (
        <figure className="absolute right-3 top-3 w-36 rounded-2xl bg-paper p-2 text-center text-navy-900 sm:w-44">
          {/* QR needs a light quiet zone around it to scan reliably */}
          <div role="img" aria-label={t.qr} className="[&>svg]:block [&>svg]:h-auto [&>svg]:w-full" dangerouslySetInnerHTML={{ __html: renderSVG(link) }} />
          <figcaption className="mt-1 text-xs leading-snug">{t.scan}</figcaption>
        </figure>
      )}

      <a href={NASA_3D} target="_blank" rel="noopener noreferrer" className="absolute bottom-1 right-3 text-xs text-fact underline underline-offset-2">
        {t.credit}
      </a>
    </div>
  )
}
```

Notes for the implementer:
- `dangerouslySetInnerHTML` is safe here: the SVG is generated by `uqr` from our own URL, not from user text.
- If `bg-paper` / `text-navy-900` are not tokens in `src/index.css` `@theme`, use the light/dark primitives that are (check the file first).
- Check the house `Button` passes `slot` through (it spreads `...rest` onto `<button>`, so it does).
